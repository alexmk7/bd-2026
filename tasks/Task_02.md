### Условие

Биржа `Binance` предоставляет доступ к архиву торгов. Данные по сырым тиковым трейдам (один трейд - одна строка) расположены по ссылке: https://data.binance.vision/?prefix=data/spot/daily/trades/ 

Название директорий (тикеры) совпадает с валютными парами. Для валютной пары `BTCUSDT`:

Базовый актив: `BTC` 
Котируемая валюта: `USDT` 


Дан parquet-файл с тиковыми сделками биржи Binance по одной торговой паре. Каждая строка соответствует одной сделке и содержит поля:

| Поле           | Тип     |
| -------------- | ------- |
| trade_id       | int64   |
| price          | float64 |
| quantity       | float64 |
| quote_qty      | float64 |
| timestamp      | int64   |
| is_buyer_maker | bool    |

Размер файла может достигать нескольких гигабайт. 

Необходимо написать программу `calc_data.py`, которая:

1. Принимает путь к parquet-файлу через аргумент командной строки.
2. Вычисляет значение:

$$
\sum_i |VWAP_i^{buy} - VWAP_i^{sell}|
$$


где:

* данные агрегируются по секундным интервалам;
* $VWAP_i^{buy}$ — VWAP всех сделок с `is_buyer_maker=False` в секунде `i`;
* $VWAP_i^{sell}$ — VWAP всех сделок с `is_buyer_maker=True` в секунде `i`.

`VWAP` определяется как

$$
VWAP = \frac{\sum price \cdot quantity}{\sum quantity}
$$

3. Вычисляет значение аналогично предыдущему, но  
`VWAP` считается по каждой календарной **минуте**  `i`.

4. Выводит результат в stdout с точностью до 6 знаков после запятой в формате:

```
VWAP_s=<число>
VWAP_m=<число>
```

1. Результат должен совпадать с эталоном. Неверный ответ даёт 0 баллов вне зависимости от скорости.
2. Баллы начисляются в зависимости от времени работы на тестовых файлах. Чем быстрее, тем больше баллов (зависит от других результатов).
3. Программа  запускаться внутри Docker-контейнера. 
4. Число доступных ядер заранее неизвестно. 
5. Ограничение памяти для контейнера: 4 Гб.
6. Решение должно работать на файлах объёмом до 10 ГБ.

Сборка контейнера будет происходить как-то так:
```bash
docker build -t calc_data .
docker run --rm -v /path/to/data:/data:ro calc_data /data/input.parquet
```

В репозитории должен быть как минимум Dockerfile и `calc_data.py`. Должен использоваться базовый образ на основе `python:3.14-slim`.

Пример:

```dockerfile
FROM python:3.14-slim

RUN apt-get update && apt-get install -y --no-install-recommends \
    gcc \
    && rm -rf /var/lib/apt/lists/*

WORKDIR /app


# COPY requirements.txt .
# RUN pip install --no-cache-dir -r requirements.txt

COPY calc_data.py .

ENTRYPOINT ["python3", "calc_data.py"]
```
